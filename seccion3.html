Clientes conectados con la web

Esta pestaña lee y escribe en la tabla clients de Supabase, que es la que usa tu web/app. Los proveedores se mantienen como contactos locales porque tu app no tiene una tabla de proveedores detectada.

Configuración

Los números de factura se generan solos con el formato PREFIJO-AÑO-0001. Los ingresos/gastos creados aquí se guardan en la tabla transactions de Supabase, que es la que usa el panel financiero de tu app.

Conexión Supabase

No se modifica tu web ni tu app. Este HTML usa la misma URL y anon key detectadas en tu app. Si Supabase tiene RLS activo, inicia sesión con tu usuario administrador.

Campos usados: transactions.type, amount, description, date, category, client_name, notes
Clientes usados: clients.name, email, phone, allergies, notes

Copias y seguridad
